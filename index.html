Mi Primera Página Web

Un lugar donde documento mi proceso de aprendizaje en la maquetación y programación web en HTML5

Sobre este sitio web

Bienvenido a mi primer proyecto Web. Este sitio fue creado como parte de la actividad del primer avance del curso de tecnología para poner en práctica la creación de páginas web y el uso de las etiquetas fundamentales de HTML5.

A través de esta página, organizo los conceptos importantes aprendidos durante el periodo de aprendizaje de la creación de una Pagina Web.

  1. Semana #1

En esta semana aprendí lo principal y primordial para crear la Pagina Web ya que aprendí a utilizar las etiquetas principales para tener lo basico

Puntos claves aprendidos:

  • Encabezado.
  • Pie de página.
  • Principales enlaces de navegación.
  • Sección de la página.
  • Artículo independiente.
  • Barra lateral.
  • Ver avance de la Semana #2

  1. Semana #2

En esta semana 2 aprendimos sobre el uso del CSS "Cascading Style Sheets" aclarando que se complementan pero no son lo mismo ya que son lenguajes diferentes, el CSS es un lenguaje de hojas de estilo en cascada y esta misma sirve para diseñar y personalizar la pagina de mejor manera, utilizando la etiqueta style, donde podemos personalizar la tipografia, el color de los parrafos, pero no solo eso, sino tambien el fondo de color de la Pagina Web, aplicando correctamente las reglas y sus propiedades.

Puntos claves aprendidos

  • Color del fondo de la Pagina Web
  • Tipografia
  • Color de texto
  • Tamaño de texto
  • Uso del id y class
  • Ver avance de la Semana #3

  1. Semana #3

En esta semana 3 aprendimos sobre el uso de las tablas en HTML para organizar la información, los comentarios dentro del código y las propiedades de texto en CSS para personalizar las fuentes y los estilos.

Puntos claves aprendidos

  • Uso de las tablas (table, tr, td, th)
  • Cómo comentar en HTML y CSS
  • Propiedades de fuente
  • Propiedades abreviadas
  • Propiedades de texto

Tabla sobre las etiquetas de tablas

Etiqueta Descripción
table Etiqueta contenedora que tendrá en su interior toda la tabla.
tr Etiqueta contenedora de cada fila de la tabla.
td Cada una de las celdas de la tabla.
th Cada una de las celdas de cabecera de la tabla.

    1. Semana #4

    Durante la cuarta semana del curso, continuamos mejorando nuestros conocimientos en HTML y CSS para enriquecer la estructura y el diseño visual de nuestro proyecto de la Pagina Web. A lo largo de estas lecciones, aprendí a implementar componentes clave de navegación y técnicas de estilizado más avanzadas.

    Puntos claves aprendidos

    • Creación de Menús de Navegación
    • Combinación de Selectores y Clases
    • Agrupación de Selectores
    • Uso de Selectores Descendientes en Listas
    • Interactividad con la Pseudoclase
    • Ver avance de la Semana #5

    1. Semana #5

    En esta quinta semana del curso nos enfocamos en profundizar en el Modelo de Caja y las propiedades de posicionamiento en CSS. Comprendimos que cada elemento HTML es visualizado como una caja rectangular compuesta por el contenido, el relleno, el borde y el margen. Además, aprendimos a maquetar y distribuir las secciones de la página web para lograr un diseño maquetado organizando, estructuras complejas como el encabezado, navegación, sección principal, barra lateral y pie de página.

    Puntos claves aprendidos

    • Modelo de Caja (Content, Padding, Border, Margin)
    • Posicionamiento CSS (static, relative, absolute, fixed, sticky)
    • Control de flujo y alineación de elementos (float y clear)
    • Maquetación y distribución de la estructura web (Header, Nav, Section, Aside, Footer)
    • Ver avance de la Semana #6

    1. Semana #6

    Durante esta sexta semana del curso exploramos el uso de Frameworks y Librerías en el desarrollo web. Comprendimos cómo herramientas como Bootstrap nos permiten acelerar el proceso de diseño y desarrollo mediante componentes prediseñados y sistemas de rejilla (grid), optimizando la adaptabilidad y el diseño responsivo de nuestros proyectos sin necesidad de escribir todo el código de estilos desde cero.

    Puntos claves aprendidos

    • Implementación de Frameworks CSS (Bootstrap)
    • Uso eficiente de componentes prediseñados (Navbar, Cards, Alertas)
    • Diseño web adaptable y responsivo
    • Estructuración de proyectos mediante CDNs
